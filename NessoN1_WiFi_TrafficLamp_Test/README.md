# Nesso N1 スマホ操作・液晶3色試験（最小版）

Nesso N1自身をWi-Fiアクセスポイントにし、スマホのブラウザからN1液晶全体を赤・黄・青・黒へ切り替える前段試験です。家庭のWi-Fiルーターや専用スマホアプリは使いません。

## 試験仕様

- N1液晶全体を赤・黄・青に切り替え
- 「消灯」で液晶を黒表示
- N1とスマホは直接Wi-Fi接続
- 今回は赤外線信号を送信しません

## Arduino IDEでの準備

1. ボードは、前回と同じ `Arduino Nesso N1` を選びます。
2. ライブラリマネージャで `M5Unified` をインストールします。
3. `secrets.example.h` を同じフォルダー内で `secrets.h` にコピーします。
4. `secrets.h` の `NESSO_AP_PASSWORD` を8文字以上の任意のパスワードに変更します。
5. `NessoN1_WiFi_TrafficLamp_Test.ino` を開いて書き込みます。
6. 書き込み時は、USB-C接続後にN1のボタンを長押ししてDownload Modeへ入れます。

`WiFi.h` と `WebServer.h` はESP32 Arduino環境に含まれるため、通常は別途インストール不要です。

## スマホから操作する

1. N1を起動します。
2. スマホのWi-Fi設定で次へ接続します。

   - SSID：`Nesso-N1-Lamp`
   - パスワード：`secrets.h` に設定したもの

3. 「インターネット接続なし」と表示されても、その接続を維持します。
4. Chrome、Safariなどで `http://192.168.4.1` を開きます。
5. `赤 点灯`、`黄 点灯`、`青 点灯`、`消灯`を順に押します。

## 正常時の結果

- スマホのボタン操作直後に、N1液晶全体が該当色になる。

## 初回コンパイル時の確認点

この試作の液晶部は `M5Unified` の `M5.Display` APIを使用しています。Nesso N1のボードパッケージ側で別の液晶APIが指定されている場合は、コンパイルエラー全文をそのまま記録してください。Wi-Fi/Web操作部はそのまま利用し、液晶の2行だけをN1付属サンプルに合わせて差し替えられます。

特に次のどれかが出た場合は、エラー全文が必要です。

- `M5Unified.h: No such file or directory`
- `M5` または `Display` が未定義
- 書き込み成功だが液晶が真っ暗、向きが違う、表示が乱れる

## 安全側の動作

- 起動直後は消灯状態です。
- ルーターやインターネットへは接続しません。
- GPIO 9の赤外線送信は使用しません。
- モーター出力はまだ行いません。
